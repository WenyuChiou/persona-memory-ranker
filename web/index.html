Synthetic conversations. Incomplete labels.

This explorer uses public PersonaMem-v2 examples. It shows retrieval behavior, not a diagnosis, a psychological profile, or proof that an assistant’s answer is correct. An update flag is a dataset annotation; history position is an order proxy, not elapsed time.

A reproducible source chain.

Showcase questions are selected deterministically by ID after topic exclusions, independently of ranking scores. Each case retains its entire saved candidate pool. Original role-tagged messages are preserved, and source links point to one fixed dataset revision.
